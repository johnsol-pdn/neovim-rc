# Установка

Достаточно простого клонирования репозитория.

## Второстепенное

### Поддержка Language Server Protocol

Включается клонированием следующего репозитория:

```
git clone https://github.com/neovim/nvim-lspconfig pack/nvim/start/nvim-lspconfig
```

И раскомментированием соответствующего блока в `init.lua`.
